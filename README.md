# Реестр погашений по банковским выпискам

Небольшое Flask-приложение для загрузки банковских выписок, справочника заемщиков и необязательных файлов расшифровок. Сервис сопоставляет платежи и возвращает итоговый `registry.xlsx`.

## Хранение файлов

- Загруженные Excel-файлы существуют только во временной системной папке во время обработки.
- После завершения или отмены обработки временная папка удаляется.
- Статус каждой операции передается ее браузеру по отдельному WebSocket-каналу.
- Идентификатор браузера создается локально без регистрации и авторизации; чужая операция по другому идентификатору недоступна.
- Обработка продолжается после обновления страницы, а вкладка автоматически восстанавливает статус операции.
- Готовый `registry.xlsx` хранится в оперативной памяти сервера до 30 минут и загружается как временный `Blob` браузера.
- Кнопка `Отменить` останавливает выполняющуюся операцию на ближайшем безопасном шаге.
- Каталоги `media` и `logs` не используются.

Итоговый Excel содержит листы `Оплата`, `Не найдено`, `Ошибки сверки`,
`Журнал пропусков` и `Свод по компаниям`. В журнале для каждой строки, которая
не является обрабатываемым входящим платежом, указана точная причина пропуска.

ФИО в назначениях платежей извлекается локальной мультиязычной моделью GLiNER 2.
При первом запуске модель `fastino/gliner2-multi-v1` загружается в кеш; в Docker
кеш сохраняется в отдельном volume и не скачивается заново после перезапуска.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Сайт будет доступен по адресу `http://127.0.0.1:8000/`.

Максимальный общий размер одной загрузки по умолчанию составляет 100 МБ. Его можно изменить:

```bash
MAX_UPLOAD_MB=200 python app.py
```

Дополнительные настройки:

```env
PROCESSING_WORKERS=4
RESULT_TTL_MINUTES=30
NER_MODEL=fastino/gliner2-multi-v1
NER_BATCH_SIZE=8
```

Сопоставление ФИО нечувствительно к регистру и порядку частей имени. Поддерживаются
инициалы с точками и без точек (`Иванов И. И.`, `И И Иванов`, `Иванов ИИ`).
Сначала проверяются исходные варианты ФИО. Если они не дали совпадения, части
имени приводятся к словарной форме без падежных окончаний и поиск повторяется.
Фамилия в одиночку, фамилия с одним инициалом и полностью сокращенное ФИО
(`И.И.И.`) не считаются достаточным совпадением.

## Docker

```bash
cp .env.example .env
docker compose up -d --build
```

По умолчанию сайт будет доступен по адресу `http://127.0.0.1:9991/`.

После обновления кода достаточно выполнить:

```bash
git pull
docker compose up -d --build
```

В `compose.yml` указан `build: .`, поэтому образ действительно пересобирается из текущего исходного кода.

## Структура

- `app.py` - фоновые операции, WebSocket и возврат результата без постоянного хранения.
- `processor/services/new_format_processor.py` - основная обработка и формирование Excel.
- `processor/services/excel_processor.py` - общие функции чтения и нормализации.
- `templates/index.html` - страница загрузки и результата.
- `static/app.js` - отправка формы и временное хранение результата в браузере.
